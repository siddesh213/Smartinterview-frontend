# Smart Interview Preparation Platform

## 🚀 Overview

Smart Interview Preparation Platform is a MERN-based web application that helps users prepare for technical interviews in a structured and personalized way.  
Users get a daily study plan based on their interview date and experience level (Student or Professional), covering DSA, DBMS, System Design, and Behavioral topics.

## 🛠 Tech Stack

- **Frontend:** React.js, Vite, Redux Toolkit, Tailwind CSS
- **Backend:** Node.js, Express.js ([Repository Link](https://github.com/siddesh213/Smartinterview-Backend))
- **State Management:** Redux Toolkit
- **Authentication:** JWT
- **Database:** MongoDB (via MongoDB Atlas)
- **Other:** REST APIs with Pagination
